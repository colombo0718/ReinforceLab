Map is_slippery

FrozenLake 對標規則（Gymnasium FrozenLake-v1）

  • Tile：🚩 Start(S) / 🟦 Frozen(F) / ⚫ Hole(H) / 🎁 Goal(G) / 🧑 Agent
  • State：stateIndex ∈ [0..N-1]（row-major：s=r*ncol+c）
  • Action：0=LEFT、1=DOWN、2=RIGHT、3=UP
  • Reward：只有到 🎁 給 +1，其餘全部 0（含掉洞）
  • Episode 結束：到 ⚫ 或 🎁 立即結束並 reset
  • is_slippery=true：動作會在「左偏/原動作/右偏」各 1/3 隨機選擇

鍵盤：WASD（W=UP, A=LEFT, S=DOWN, D=RIGHT）。
