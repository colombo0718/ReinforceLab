Task Description

There are 5 slot machines (A0 ~ A4). Each step, choose one to pull. The agent must balance exploring unknown machines against exploiting the best-known one. Every 10 pulls counts as one episode.

🎯 Reward
  • Each pull draws a random result from that machine's reward pool
  • ❌: 0 pts ／ 🍬: 1 pt ／ 🪙: 3 pts ／ 💎: 10 pts
  • Uniform: all machines share the same pool
  • Fixed Rewards: two all-❌, two all-🍬, one all-🪙
  • Slight Difference: machines have slightly different expected values
  • Hidden Jackpot: four normal machines, one hides a high-rate 💎 pool
🧭 State
  • selectedMachine: index of the currently selected machine (0 ~ 4)
🕹️ Actions
  • 0: A0 ／ 1: A1 ／ 2: A2 ／ 3: A3 ／ 4: A4
⚙️ Suggested Parameters

Beginner

  • bins = 1
  • ε = 0.3, α = 0.5
  • Recommended: Slight Difference

Advanced

  • Decay ε, compare strategy differences
  • Switch modes to observe adaptation speed
