Task Description

The agent navigates a 10×10 grid map, starting from a spawn point and finding a path to the goal. The map may contain walls, coins, hazards, and rockets that teleport directly to the goal.

🎯 Reward
  • Reach goal 🏆: +10, episode ends
  • Pick up coin 💰: small positive reward
  • Step on bomb 💣 / fire 🔥: negative reward, episode ends
  • Step on rocket 🚀: teleport to goal
🧭 State
  • playerX: agent X position (0 ~ 500)
  • playerY: agent Y position (0 ~ 500)
🕹️ Actions
  • 0: none (stay)
  • 1: right ／ 2: down ／ 3: left ／ 4: up
⚙️ Suggested Parameters

Beginner

  • bins = 10, ε = 0.3
  • α = 0.5, γ = 0.9
  • Start with Open Field

Advanced

  • Try levels with obstacles
  • Observe the Q-Table heatmap
  • Compare convergence speed across levels
