Task Description

The helicopter 🚁 continuously advances through a flight corridor while gravity pulls it down. The agent must flap upward at the right moment to pass through wall gaps without crashing into walls or flying out of bounds.

🎯 Reward
  • Pass through a wall gap: +1
  • Survive each frame: +0.01 (small positive feedback)
  • Crash into wall or fly out of bounds: episode ends
🧭 State
  • heliY: helicopter height (center = 0, bottom = -250, top = +250)
  • wallDistance: horizontal distance to the next wall
  • gapCenterY: center height of the next wall gap
🕹️ Actions
  • 0: none (fall)
  • 1: flap (thrust upward)
⚙️ Suggested Parameters

Beginner

  • bins = 6, ε = 0.3
  • α = 0.5, γ = 0.95
  • Recommended: Fixed Height mode

Advanced

  • Switch to Large Random mode
  • bins = 8 for higher resolution
  • Observe Q-Table heatmap convergence
