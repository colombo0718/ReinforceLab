Task Description

Control the fighter ✈️ to move left and right in space, firing lightning ⚡ to hit asteroids 🪨. The first three modes use stationary targets; the last two have asteroids falling from above — getting close is both an opportunity and a risk. Hit 10 asteroids to complete the episode.

🎯 Reward
  • Hit asteroid: +10, triggers explosion 💥
  • Bullet exits top without hitting: -1
  • Asteroid collides with plane: -100, episode ends, triggers 💥
  • Hit 10 asteroids: episode ends successfully
🧭 State (5D, continuous)
  • playerX: plane horizontal position (center = 0, left negative, right positive)
  • rockX: asteroid horizontal position (same coordinate system)
  • rockY: asteroid vertical position (positive = up, negative = down)
  • rockVX: asteroid horizontal velocity (0 in stationary modes)
  • rockVY: asteroid vertical velocity (0 in stationary modes)
🕹️ Actions
  • 0: none (coast by inertia)
  • 1: left (accelerate left)
  • 2: right (accelerate right)
  • 3: shoot (fire ⚡)
⚙️ Suggested Parameters

Beginner

  • Start with Fixed Target
  • bins = 6, ε = 0.3
  • Progress through modes, compare convergence

Advanced

  • Moving Target mode, bins = 8
  • Observe how rockVY affects firing timing
  • Compare Q-values for dodge vs. shoot
