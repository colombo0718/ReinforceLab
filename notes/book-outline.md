# 《人人必學 AI 靈感編程》書籍規劃

> 核心定位：Vibe Coding × 網頁遊戲是對外的 hook，帶到 RL 與 RR 平台才是深度所在與主要目的。

---

## 核心教學機制：配套 md 約束文件

每一章實作開發前，讀者將**該章配套的 md 規格文件**交給 AI，作為技術護欄。
- **讀者負責**：天馬行空的創意、遊戲主題、玩法想法
- **md 負責**：技術約束、結構規格、RR 相容性保證
- **AI 負責**：在約束範圍內生成合規程式碼

配套 md 跨章累積，到後期接入 RR 時，讀者把所有章節 md 一次交給 AI，自然生出完整合規的訓練環境。

---

## 章節規劃

### Ch01 AI 靈感編程入門
**配套 md**：基本網頁結構約束（HTML / CSS / JS 框架規格，禁用外部套件）

1-1 Vibe Coding 方法論：最小可行
1-2 認識最基本的網頁結構（HTML / CSS / JavaScript）
1-3 看懂 AI 產生的程式碼在做什麼
1-4 小幅修改與測試，建立控制感
1-5 實作：個人名片網頁

---

### Ch02 網頁互動基礎
**配套 md**：遊戲迴圈規格（requestAnimationFrame、座標系統、事件監聽介面）

2-1 Vibe Coding 方法論：一次一件
2-2 螢幕座標與畫面更新概念
2-3 點擊、鍵盤與觸控操作
2-4 角色移動與基本遊戲迴圈
2-5 實作：太空戰機遊戲

---

### Ch03 經典玩法拆解
**配套 md**：玩法機制配方（追逐 / 閃避 / 收集三種模板，碰撞判斷規格）

3-1 Vibe Coding 方法論：照著改
3-2 經典遊戲機制分析（跑酷、閃避、追逐）
3-3 障礙物、敵人與碰撞判斷
3-4 生命、分數與勝敗條件
3-5 實作：Emoji 跑酷遊戲

> **Emoji 作為視覺素材**：解決美術門檻，讓作品立即好看可展示，幾乎零成本。

---

### Ch04 數值與心流設計
**配套 md**：數值設計規範（速度、間隔、難度曲線的參數範圍與設計禁忌）

4-1 Vibe Coding 方法論：用數字說話
4-2 為什麼遊戲會太難或太無聊（心流概念）
4-3 速度、間隔與難度遞增設計
4-4 請 AI 協助分析與微調數值
4-5 實作：難度循序遞增的 Emoji 遊戲

---

### Ch05 讓你的遊戲能被 AI 控制
**配套 md**：Action / State / Reward 設計規格 + RR postMessage 通訊協定

> **本章是全書樞紐**：前四章做出遊戲，本章讓遊戲成為合格的 RL 訓練環境。

5-1 Vibe Coding 方法論：先定規格，再動手
5-2 什麼是 Action？從你的遊戲出發定義按鍵集合
5-3 什麼是 State？AI 看得到什麼、需要知道什麼
5-4 什麼是 Reward？設計回饋訊號，而不只是分數
5-5 實作：postMessage 接入 RR（50 行 boilerplate，Vibe Coding 完成）

**配套 md 內容涵蓋**：
- Action 規格：離散 / 連續、數量上限
- State Contract：固定 key、維度上限（16/32 維）、值域範圍、正規化規則
- Reward 設計規範：正向回饋 vs 終局懲罰，禁忌（稀疏 reward / 洩漏分數）
- RR 通訊協定：`gameInfo` 宣告格式、`reward_state` 回傳格式、`done: true` 規則

---

### Ch06 用遊戲理解強化式學習
**配套 md**：RL 核心概念對照表（遊戲語言 ↔ RL 術語）

6-1 Vibe Coding 方法論：先設結構
6-2 從遊戲視角理解 State / Action / Reward
6-3 一局遊戲就是一次學習（Episode 概念）
6-4 探索 vs 利用：AI 的新手期與老手期
6-5 實作：AI 看得懂的遊戲狀態（驗證 State 設計）

---

### Ch07 AI 自動遊玩訓練實戰
**配套 md**：RR 訓練參數說明（Q-learning / DQN 切換、ε 衰減、學習率建議值）

7-1 Vibe Coding 方法論：先看行為
7-2 認識 RR 的訓練流程與儀表板
7-3 觀察 AI 學習曲線（reward 曲線、成功率）
7-4 找出訓練瓶頸（AI 學不動時的故障清單）
7-5 實作：訓練 AI 自動破關你做的遊戲

---

### Ch08 成果整理與精準駕馭
**配套 md**：作品發布規格 + AI 可讀 md 筆記模板

8-1 Vibe Coding 方法論：總結流程
8-2 整理專案結構（讓作品可分享、可維護）
8-3 建立 AI 可讀的 md 筆記（讓下次 Vibe Coding 更精準）
8-4 從求神問卜到精準駕馭（累積 md 就是累積控制力）
8-5 實作：完整 AI 網頁遊戲成果專案上線

---

## 配套 md 累積路線

```
Ch01  網頁結構 md
Ch02  遊戲迴圈 md
Ch03  玩法機制 md
Ch04  數值設計 md
         ↓ 遊戲本體完成
Ch05  Action + State + Reward + RR 協定 md   ← 全部交給 AI，遊戲接上 RR
Ch06  RL 概念對照 md
Ch07  訓練參數 md
Ch08  發布規格 md
         ↓ 8 份 md 累積完畢 = 讀者的個人 AI 知識庫
```

## 營隊使用版本

三天密集（18 小時）對應：
- Day 1（Ch01–04）：做出可玩的 Emoji 遊戲
- Day 2（Ch05–06）：接入 RR，理解 RL 概念
- Day 3（Ch07–08）：訓練 AI、Showcase 擂台賽

> 每位學員學費含一本書，書即教材也是規格書與除錯手冊。
